### Hi, I'm Oğuz 👋

I'm a ship's captain who writes software. Most of what's here started as a tool I needed on board: offline apps for voyage planning, cargo stowage, vetting inspections and maritime English. The rest are desktop and media apps I use at home. Everything runs locally and keeps working without an internet connection.

## ⚓ Maritime tools

| Project | What it does |
|---|---|
| [**Captain ETA**](https://github.com/kaptanoguz/CaptainETA) | Voyage ETA and passage-planning calculator: sea-route distances between 230+ ports, port stays, fuel and CO₂, telex-style ETA message and PDF. Runs in the browser. |
| [**Cargo Optimizer**](https://github.com/kaptanoguz/Cargo-Optimizer) | Chemical tanker stowage planner: optimal tank allocation with IBC Code ship type and segregation checks, filling limits, list and deadweight. C++/WebAssembly search engine. |
| [**Vetting Inspector**](https://github.com/kaptanoguz/VettingInspector) | SIRE 2.0 vetting preparation by rank: the full questionnaire, company procedure for every question, interview practice, exam and a printable report. |
| [**Ada Translate**](https://github.com/kaptanoguz/AdaTranslate) | Offline English ↔ Turkish maritime dictionary (5,800+ terms) and on-device sentence translation for seafarers. Windows desktop app. |

## 🖥️ Desktop and media apps

| Project | What it does |
|---|---|
| [**Loupe**](https://github.com/kaptanoguz/Loupe) | Local-first photo catalog: offline face recognition, semantic search, Wi-Fi transfer from your phone and encrypted cloud backup. Rust + Tauri. |
| [**ShiftDrop**](https://github.com/kaptanoguz/ShiftDrop) | Drag a file, tap Shift, drop it on a wheel to convert: images, video, audio, PDF and documents, fully offline. Linux and Windows. |
| [**Homeflix**](https://github.com/kaptanoguz/Homeflix_2) | Self-hosted, Netflix-style home media server for your own movies and series, with posters, collections, resume and subtitles. |
| [**Torrent Bul**](https://github.com/kaptanoguz/torrent) | Simple torrent search and download app built on qBittorrent, with ratings, posters and streaming while downloading. |
